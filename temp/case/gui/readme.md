1、使用popdf、pyside6开发一个简单的gui，实现pdf文件的转换为word文件
2、可以实现单个pdf的转换，也可以实现批量转换，并且转换后的文件可以指定输出目录
3、转换完成后，可以在gui中显示转换结果，包括转换的文件数量、转换的文件大小等
4、可以在gui中添加一个按钮，点击后可以打开转换结果的目录
5、可以在gui中添加一个按钮，点击后可以退出程序
6、可以在gui中添加一个按钮，点击后可以打开关于窗口，显示版本信息、作者信息等
7、可以在gui中添加一个按钮，点击后可以打开帮助窗口，显示使用说明、常见问题等
8、可以在gui中添加一个按钮，点击后可以打开设置窗口，设置转换参数，如转换质量、转换速度等
9、画面尽量好看，有科技感，如使用material design等设计规范
