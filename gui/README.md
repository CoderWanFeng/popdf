# PDF 工具箱 GUI

基于 PySide6 和 popdf 库的 PDF 处理桌面应用程序。

## 功能特性

- ✅ **PDF 转 Word** - 将 PDF 文件转换为可编辑的 Word 文档
- ✅ **PDF 转图片** - 将 PDF 页面转换为图片格式（支持单张或多张）
- ✅ **文本转 PDF** - 将文本文件转换为 PDF 格式
- ✅ **PDF 分割** - 按页面范围分割 PDF 文件
- ✅ **PDF 加密** - 为 PDF 文件添加密码保护
- ✅ **PDF 解密** - 移除 PDF 文件的密码保护
- ✅ **添加水印** - 在 PDF 文件中添加自定义文本水印
- ✅ **PDF 合并** - 将多个 PDF 文件合并为一个
- ✅ **删除页面** - 删除 PDF 中的指定页面
- ✅ **批量处理** - 所有功能都支持单个文件和批量处理

## 安装和使用

### 方式一：直接运行源代码

1. 确保已安装 Python 3.7+
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行应用程序：
   ```bash
   python run.py
   ```

### 方式二：打包为可执行文件

1. 运行打包脚本：
   ```bash
   python build.py
   ```
2. 打包完成后，在 `release` 文件夹中找到 `PDF工具箱.exe`
3. 直接双击运行可执行文件

## 界面说明

应用程序采用标签页设计，每个功能对应一个标签页：

### 通用操作流程

1. **选择输入**：
   - 单个文件：选择具体的 PDF 文件
   - 批量处理：选择包含多个 PDF 文件的文件夹

2. **设置输出**：
   - 单个文件：指定输出文件路径
   - 批量处理：指定输出文件夹

3. **配置参数**：根据功能需要设置相应参数（如页码、密码、水印文本等）

4. **开始处理**：点击开始按钮执行操作

### 功能详情

#### PDF 转 Word
- 输入：PDF 文件
- 输出：Word 文档 (.docx)
- 支持单个和批量转换

#### PDF 转图片
- 输入：PDF 文件
- 输出：图片文件 (.jpg/.png)
- 选项：是否合并为单张图片

#### 文本转 PDF
- 输入：文本文件 (.txt)
- 输出：PDF 文件
- 支持单个和批量转换

#### PDF 分割
- 输入：PDF 文件
- 输出：分割后的 PDF 文件
- 参数：起始页码、结束页码

#### PDF 加密/解密
- 输入：PDF 文件
- 输出：加密/解密后的 PDF 文件
- 参数：密码

#### 添加水印
- 输入：PDF 文件
- 输出：带水印的 PDF 文件
- 参数：水印文本、位置、字体大小

#### PDF 合并
- 输入：多个 PDF 文件列表
- 输出：合并后的 PDF 文件
- 操作：通过添加文件按钮选择多个文件

#### 删除页面
- 输入：PDF 文件
- 输出：删除指定页面后的 PDF 文件
- 参数：要删除的页码（支持范围，如 1,3,5-8）

## 系统要求

- **操作系统**：Windows 7/8/10/11（推荐 Windows 10+）
- **内存**：至少 2GB RAM
- **磁盘空间**：足够的空间用于文件处理
- **Python**（仅源代码运行需要）：Python 3.7+

## 注意事项

1. **文件权限**：确保应用程序有读写文件的权限
2. **文件路径**：避免使用包含中文或特殊字符的路径
3. **大文件处理**：处理大型 PDF 文件时可能需要较长时间
4. **批量处理**：批量处理大量文件时请耐心等待
5. **备份文件**：建议在处理重要文件前先备份

## 故障排除

### 常见问题

**Q: 应用程序无法启动**
A: 检查是否安装了所有依赖包，或尝试重新打包可执行文件

**Q: 文件处理失败**
A: 检查文件路径是否正确，文件是否被其他程序占用

**Q: 批量处理不工作**
A: 确保输入文件夹包含有效的 PDF 文件，输出文件夹有写入权限

**Q: 内存不足**
A: 关闭其他程序释放内存，或分批处理大文件

### 日志查看

应用程序会在控制台输出处理日志，如遇问题可查看相关错误信息。

## 技术架构

- **GUI 框架**：PySide6（Qt for Python）
- **PDF 处理**：popdf 库（基于 PyMuPDF、PyPDF2）
- **多线程**：使用 QThread 实现后台处理
- **打包工具**：PyInstaller
