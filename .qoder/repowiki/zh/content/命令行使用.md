## 简介

`popdf` 是一个基于 Python 的 PDF 自动化处理库，提供了丰富的命令行接口（CLI），通过 `click` 框架实现。用户可以通过简单的命令行指令完成 PDF 转 Word、PDF 转图片、加密解密、合并分割等多种操作。本指南将详细介绍如何使用 `popdf` 的命令行功能。

**文档来源**  
- [README.md](file://README.md#L25-L58)

## CLI命令结构

`popdf` 的命令行工具基于 `click.group()` 构建，主命令为 `popdf`，所有功能作为子命令组织。命令结构遵循标准的 CLI 语法：

```
popdf [子命令] [参数选项]
```

入口点定义在 `setup.cfg` 和 `pyproject.toml` 中，指向 `popdf.api.pdf:cli` 函数。`cli()` 函数使用 `@click.group()` 装饰器注册为命令组，所有子命令通过该组进行管理。

## 核心功能命令详解

### pdf2docx：PDF转Word

将 PDF 文件转换为 Word 文档（.docx 格式）。

**语法**：
```
popdf pdf2docx --input-file <输入文件> --output-file <输出文件>
```

**示例**：
```bash
popdf pdf2docx --input-file example.pdf --output-file example.docx
```

支持批量转换：
```bash
popdf pdf2docx --input-path ./pdfs --output-path ./docs
```

**文档来源**  
- [pdf.py](file://popdf/api/pdf.py#L17-L43)

### pdf2imgs：PDF转图片

将 PDF 文件转换为图片格式（如 JPG、PNG）。

**语法**：
```
popdf pdf2imgs --input-file <输入文件> --output-file <输出目录> [--merge]
```

**示例**：
```bash
popdf pdf2imgs --input-file example.pdf --output-file ./images
```

合并为单张图片：
```bash
popdf pdf2imgs --input-file example.pdf --output-file output.jpg --merge
```

批量转换：
```bash
popdf pdf2imgs --input-path ./pdfs --output-path ./images
```

## 输入输出路径配置

`popdf` 支持两种处理模式：单文件处理和批量处理。

- **单文件模式**：使用 `--input-file` 和 `--output-file` 参数指定单个输入输出文件路径。
- **批量模式**：使用 `--input-path` 和 `--output-path` 参数指定输入和输出目录，工具会自动处理目录下所有符合条件的文件。

输出目录若不存在，工具会自动创建。建议使用绝对路径或相对于当前工作目录的相对路径。

## 处理选项与安全设置

### 页码参数

在 `split4pdf` 和 `del4pdf` 命令中，页码从 1 开始计数（用户视角），但在内部处理时转换为 0 基索引。

- `--from-page`：起始页码，默认为 1。
- `--to-page`：结束页码，-1 表示到最后一页。

### 安全设置

- **加密**：使用 `--password` 参数设置强密码，建议长度不少于 8 位，包含字母、数字和特殊字符。
- **解密**：确保输入正确的密码，否则会报错。

### 水印设置

`add_text_watermark` 支持自定义字体、字号和颜色：
- `--fontname`：字体名称（如 Helvetica、Times-Roman）
- `--fontsize`：字体大小
- `--color`：RGB 颜色值，如 "(1,0,0)" 表示红色

## 常见错误处理

### 参数错误

当参数填写不正确时，系统会输出错误信息并提供文档链接：
```
参数填写错误，详见：http://www.python4office.cn/python-office/popdf/%E8%AF%BE%E7%A8%8B/1-pdf2docx/
```

**解决方法**：检查参数名称和值是否正确，确保必填参数已提供。

### 文件路径错误

- **输入文件不存在**：检查文件路径拼写和文件是否存在。
- **输出目录不可写**：确保有写入权限，或指定其他目录。

### 批量处理无文件

```
没有找到要处理的PDF文件
```

**解决方法**：确认输入目录中包含 `.pdf` 文件，或检查文件扩展名是否正确。

### 解密失败

```
PdfReadError: File has not been decrypted
```

**解决方法**：确认密码正确，或检查文件是否已被损坏。
