## 添加新功能

为项目添加新功能需要遵循以下步骤：

1. 在`examples`目录下创建使用案例
2. 在`popdf/api/pdf.py`中添加API接口
3. 在`popdf/core`中实现核心逻辑
4. 在`popdf/lib`中添加必要的工具函数
5. 在`tests/test_code`中编写单元测试

```mermaid
flowchart TD
A[创建使用案例] --> B[添加API接口]
B --> C[实现核心逻辑]
C --> D[添加工具函数]
D --> E[编写单元测试]
E --> F[提交PR]
```

## 贡献代码

欢迎任何人参与项目开发。贡献代码的步骤如下：

1. Fork项目到自己的仓库
2. 克隆到本地进行修改
3. 提交代码并推送到自己的仓库
4. 创建Pull Request到主分支
5. 等待作者合并
