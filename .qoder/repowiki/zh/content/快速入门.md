## 简介

`popdf` 是一个专为Python自动化办公设计的PDF处理库，提供简洁易用的API来完成常见的PDF操作任务。本教程将引导您从零开始，通过`examples/course/code`目录下的示例代码，快速掌握核心功能的使用方法。

所有功能均通过统一的`popdf`接口调用，无需深入了解底层实现细节，即可在5分钟内完成第一个PDF处理任务。

## 核心功能快速上手

### PDF转Word

将PDF文件转换为Word文档（.docx格式）是常见需求。使用`popdf.pdf2docx()`函数即可轻松实现。

```python
import popdf

popdf.pdf2docx(
    input_file=r'test_files/pdf/程序员晚枫.pdf',
    output_file=r'test_files/docx/输出文档.docx'
)
```

**关键参数说明：**
- `input_file`: 输入PDF文件的路径
- `output_file`: 输出Word文件的路径，必须包含`.docx`后缀

该功能基于`pdf2docx`库实现，确保了转换质量。

### PDF转图片

将PDF每一页转换为独立的图片文件，适用于需要图像化展示的场景。

```python
import popdf

popdf.pdf2imgs(
    input_file=r'test_files/pdf/程序员晚枫.pdf',
    output_path='./test_files/img/'
)
```

**关键参数说明：**
- `input_file`: 输入PDF文件路径
- `output_path`: 输出图片的目录路径

默认情况下，每页生成一张JPG图片，命名格式为`原文件名-页码.jpg`。您也可以通过`merge=True`参数将所有页面合并为一张长图。

### 按页切割PDF

从PDF中提取指定页码范围的内容，生成新的PDF文件。

```python
import popdf

# 提取第1到第3页
popdf.split4pdf(
    input_file='test_files/pdf/完整文档.pdf',
    output_file='test_files/pdf/切割后文档.pdf',
    from_page=1,
    to_page=3
)
```

**关键参数说明：**
- `from_page`: 起始页码（从1开始）
- `to_page`: 结束页码（包含），若为-1则表示到最后一页

支持单文件操作和批量处理。

### PDF加密与解密

#### 加密PDF

为PDF文件添加密码保护，防止未授权访问。

```python
import popdf

popdf.encrypt4pdf(
    input_file='test_files/pdf/原始文档.pdf',
    password='123456',
    output_file='test_files/pdf/加密文档.pdf'
)
```

#### 解密PDF

移除PDF文件的密码保护。

```python
popdf.decrypt4pdf(
    input_file='test_files/pdf/加密文档.pdf',
    password='123456',
    output_file='test_files/pdf/解密文档.pdf'
)
```

**注意事项：** 必须提供正确的密码才能成功解密。

### 添加文本水印

在PDF文档中添加自定义文本水印，用于标识版权或状态。

```python
import popdf

popdf.add_text_watermark(
    input_file='test_files/pdf/原始文档.pdf',
    point=(100, 100),  # 水印位置 (x, y)
    text='内部文档',
    output_file='test_files/pdf/带水印文档.pdf',
    fontsize=24,
    color=(0.5, 0.5, 0.5)  # 灰色
)
```

**关键参数说明：**
- `point`: 水印文本的坐标位置
- `text`: 水印内容
- `fontsize`: 字体大小
- `color`: 颜色，RGB三元组（0-1范围）

## 常见注意事项

1. **文件路径处理**：建议使用绝对路径或基于`os.path`的相对路径构造，避免因工作目录不同导致文件找不到。
2. **输出目录存在性**：确保输出路径的目录已存在，或使用`pofile.mkdir`等工具自动创建。
3. **参数优先级**：当同时提供`input_file`和`input_path`时，优先处理单个文件。
4. **版本兼容性**：API设计考虑了版本兼容性，旧版参数仍可使用。
5. **错误处理**：函数内部包含参数校验和日志记录，便于排查问题。
